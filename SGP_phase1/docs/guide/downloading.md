Learn how to download files from ShareJadPi to any device.

## Quick Download

1. Find your file in the file list
2. Click the **Download** button (📥)
3. File saves to your device's Downloads folder

That's it!

---

## From Different Devices

**Desktop:** Click download → File saves automatically  
**Mobile:** Tap download → Choose save location or view in browser  
**Tablet:** Same as mobile

---
